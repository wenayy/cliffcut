# Outputs

Raw, unedited runs, exactly as Cliffcut wrote them, on shows written for this repo (scripts in `samples/`).
Each file holds every promo with its segments (episode, start, end, in order), the hook, the cliffhanger, why it
works, the evidence, scores with a reason for every point, the code checks, the judge verdicts, the candidates the
checks rejected, and (where made) teasers and whole-show trailers.

| File | Show | Format |
|---|---|---|
| `demo-show-maid-who-owned-the-house.json` | The demo show, 3 episodes, with trailers and teasers | Kuku's timestamped format |
| `thriller-kuku-format.json` | Thriller | Kuku's format |
| `crime-subtitles-vtt.json` | Crime | WebVTT subtitles |
| `horror-subtitles-srt.json` | Horror | SRT subtitles |
| `fantasy-screenplay.json` | Fantasy | Fountain screenplay |
| `comedy-screenplay.json` | Comedy | Fountain screenplay |
| `mythology-hindi-screenplay.json` | Mythology | Hindi screenplay |
| `hinglish-screenplay.json` | Hinglish drama | Screenplay |

The run on Kuku's own 50-episode pack is not here: that content is Kuku's and must not be published.
It is shared with Kuku by link only.
